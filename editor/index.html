TrendRadar 可视化配置编辑器 · Visual Config Studio

开源 AI 舆情监控与热点聚合工具 TrendRadar 的官方在线可视化配置工作台。纯浏览器本地运行，零数据上传，支持中英双语切换、引导式分步上手与专业源码双向联动。

Official client-side visual configuration studio for TrendRadar — configure hotlist platforms, RSS feeds, scheduled web search, keyword DSL rules, AI semantic filtering, multi-channel notifications, and 7x24h push timelines directly in your browser with zero server uploads.

核心配置能力 / Supported Configuration Files

  • config/config.yaml — 热榜平台、RSS 订阅、联网搜索、共享 AI 模型、报告版面、飞书/钉钉/企微/Telegram/邮件推送与 S3/本地存储
  • config/frequency_words.txt — 零成本关键词分组、+必含词、!排除词、正则表达式与实时标题命中沙盒
  • config/search_queries.txt — 定时联网搜索主题、站点过滤与质量分门槛
  • config/timeline.yaml — 可视化 7×24h 推送与静默 AI 时间线编排
  • config/ai_interests.txt & Prompt 模板 — AI 自然语言智能筛选、深度分析与多语言翻译提示词
